# VERITY Edition

Браузерная voxel-песочница на Three.js: процедурный мир с чанками 16×16, блочная генерация рельефа, AABB-физика игрока, добыча и установка блоков, хотбар/инвентарь, сохранение в localStorage, овцы и особенный моб VERITY с надписью HELLO и синтезированным звуком.

## Запуск

Из-за ES-модулей браузер не открывает проект через `file://`. Запусти локальный HTTP-сервер в папке проекта:

- Python: `python -m http.server 8000`
- Затем открой `http://localhost:8000`.

Или загрузи все файлы репозитория на GitHub и включи **Settings → Pages → Deploy from a branch**. После публикации открой адрес Pages.

Three.js загружается с jsDelivr CDN, поэтому для запуска нужен интернет.

## Управление

- WASD — движение, мышь — обзор, Space — прыжок, Shift — медленнее идти.
- ЛКМ — добыча блоков / удар мобов, ПКМ — поставить блок.
- 1–9 или колесо мыши — выбор слота, E — инвентарь, Esc — пауза.
- На телефоне: левый джойстик, свайп по правой части экрана, экранные кнопки.

Мир автоматически сохраняется в localStorage при паузе и выходе в меню.


## Важно для GitHub Pages
Загрузи содержимое папки `verity-edition` в корень репозитория: `index.html`, `style.css`, папку `js/` и `README.md` должны быть видны сразу на главной странице репозитория. Не загружай саму папку `verity-edition` как вложенную папку, если Pages настроен на `/(root)`.
